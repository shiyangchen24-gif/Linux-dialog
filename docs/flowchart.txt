【圖 3】dialog 如何把使用者輸入存進變數

   choice=$(dialog --menu ... 3>&1 1>&2 2>&3)

   交換前（預設）                   交換後
   ---------------------            ------------------------------------
   stdout(1) --> 畫面               fd 3      --> $( )   (先記住原本的 stdout)
   stderr(2) --> 使用者輸入         stdout(1) --> stderr --> 終端機畫面
                                    stderr(2) --> fd 3   --> $( ) --> 變數

        +--------+   畫面 (1->2)    +----------+
        | dialog | ---------------> |  終端機  |
        |        |                  +----------+
        |        |   輸入 (2->3)    +----------+
        |        | ---------------> | 變數     |
        +--------+                  | $choice  |
                                    +----------+
